# Homebrew distribution uses `homebrew_casks`, not `brews`

**Date:** 2026-06-03
**Repo:** tolvi

## Why

GoReleaser v2.16.0 (the version in use) deprecated the `brews` key that generated Homebrew formulas. The migration path is `homebrew_casks`, which handles binary distribution for both GUI apps and CLI tools despite the naming suggesting GUI-only use.

## How

- `.goreleaser.yaml` uses `homebrew_casks` with `ids: [tolvi]`, `directory: Casks`, and the full repository/commit config pointing at `tolvi-labs/homebrew-tap`
- `goreleaser check` validates cleanly with no deprecation warnings under `homebrew_casks`
- `brews`-era fields `install:`, `test:`, and `license:` are not valid in `homebrew_casks`; GoReleaser handles binary installation automatically
- A dedicated `HOMEBREW_TAP_TOKEN` fine-grained PAT (scoped to `tolvi-labs/homebrew-tap`, Contents: read+write) is required — `GITHUB_TOKEN` in Actions cannot push to a different repo in the same org
- `tolvi-labs/homebrew-tap` public repo was created; the `Casks/tolvi.rb` file will be auto-generated by GoReleaser on the next `v*` tag push
- Install path for users after first cask-enabled release: `brew tap tolvi-labs/tap && brew install --cask tolvi-labs/tap/tolvi`

## Outcome

The GoReleaser config validates cleanly; Homebrew cask distribution will be active on the `v0.1.1` tag once `HOMEBREW_TAP_TOKEN` is added as a repo secret.
